# Folio для Windows

Та же локальная вики, что и [Folio для macOS](../README.md), — для Windows 10 и 11. Страницы — Markdown-файлы в ваших папках, у каждого пространства своя история в git.

Формат пространств общий с версией для macOS: `.folio\space.json`, страница — папка с `index.md`, те же шапки, ссылки `[[…]]`, шаблоны в `_Шаблоны` и `CLAUDE.md`. Одну и ту же папку можно открывать на Mac и на Windows — например, синхронизируя её через git.

## Установка

1. Скачайте `Folio_<версия>_x64-setup.exe` со страницы [выпусков](https://github.com/Dubious-Idea/folio/releases/latest) и запустите. Установка идёт в профиль пользователя (`%LOCALAPPDATA%\Folio`), права администратора не нужны.
2. Установщик не подписан сертификатом, поэтому SmartScreen может его остановить: **Подробнее → Выполнить в любом случае**.
3. При первом запуске Folio предложит создать пространства «Работа» и «Личное» в `C:\Users\<имя>\Folio`.

Нужен WebView2 — в Windows 11 он уже есть, в Windows 10 установщик скачает его сам.

## Утилита командной строки

**Настройки → Командная строка → Добавить в PATH**, затем откройте терминал заново. Команды те же, что на macOS: `folio tree`, `folio new`, `folio search`, `folio open --edit`, `folio rename`, `folio check`, `folio commit` и другие — `folio --help`.

`folio open` открывает страницу в уже запущенном окне по ссылке `folio://open?…`; схему регистрирует установщик.

## Отличия от версии для macOS

| macOS | Windows |
| --- | --- |
| ⌘E — правка, ⌘N — новая страница, ⇧⌘N — новое окно | Ctrl+E, Ctrl+N, Ctrl+Shift+N |
| ⌘[ и ⌘] — назад и вперёд | Alt+← и Alt+→, боковые кнопки мыши |
| ⌥⌘R — показать в Finder | Ctrl+Alt+R — показать в Проводнике |
| ⌥⇧⌘C — скопировать путь, ⌥⌘S — снимок в истории | Ctrl+Alt+Shift+C, Ctrl+Alt+S |
| Переименовать — через меню | F2; Delete в дереве — в Корзину |
| ⌘-щелчок по ссылке в режиме правки | Ctrl+щелчок |
| Git из Xcode Command Line Tools | Git встроен (libgit2), ставить Git для Windows не нужно |
| `/opt/homebrew/bin/folio` | `%LOCALAPPDATA%\Folio\bin\folio.exe` в PATH пользователя |

В именах папок Windows не допускает `< > " | ? *` и имена вроде `CON` или `COM1`: Folio для Windows заменяет такие символы дефисом. Folio для macOS их оставляет, поэтому страницу с такими символами в заголовке, созданную на Mac, стоит переименовать там же, иначе её папка не появится на Windows.

## Быстродействие

Главное отличие от версии для macOS — обновления точечные:

- правка страницы перечитывает одну шапку и переиндексирует один файл, а не обходит всё пространство после каждого автосохранения;
- своё эхо от наблюдателя за папкой (ReadDirectoryChangesW) приложение узнаёт по времени записи и не перерисовывает страницу;
- дерево сканируется параллельно, а время изменения файлов берётся из той же выдачи папки, что и список подстраниц, — без отдельного обращения к каждому файлу;
- список всех страниц для подсказки `[[` передаётся редактору один раз на версию дерева, а не с каждой страницей;
- история, статус git и старые версии читаются в процессе через libgit2, без запуска `git.exe`;
- поиск идёт по отдельному соединению SQLite и не ждёт, пока индекс обновляется;
- длинное дерево рисуется виртуально — только видимые строки.

Замер ядра на синтетическом пространстве: `cargo run --release -p folio-core --example bench -- 5000`.

## Разработка

Нужны Rust (stable, MSVC), Visual Studio Build Tools с компонентом C++ и Node.js 22+.

```powershell
windows\scripts\build.ps1            # тесты, folio.exe и установщик в windows\target\release\bundle\nsis
windows\scripts\build.ps1 -SkipTests
```

Для отладки: соберите редактор (`cd web; npm ci; npm run build`), затем в `windows` — `npm ci` и `npx tauri dev`.

Тесты: `cargo test --workspace` в `windows` (ядро, утилита, приложение), `npm test` в `web`, `npm run typecheck` в `windows`.

Устройство:

- `crates/folio-core` — модель страниц, сканер, ссылки, индекс поиска (SQLite FTS5), история (libgit2). Перенос `Sources/FolioCore` с теми же тестами.
- `crates/folio-cli` — утилита `folio`.
- `app` — приложение на Tauri 2: состояние библиотеки, наблюдение за папками, команды для интерфейса, раздача вложений по схеме `folio`, обновления.
- `shell` — интерфейс окна на SolidJS: дерево, поиск, инспектор, диалоги.
- `../web` — редактор страниц на TipTap, общий с версией для macOS; в окне Windows он живёт во фрейме.

## Обновления

Приложение проверяет `latest.json` последнего выпуска на GitHub при запуске и каждые 6 часов, скачивает установщик в фоне и ставит его при выходе (или сразу — «Перезапустить для версии X»).

Установщики подписываются ключом updater Tauri. Публичный ключ записан в `app/tauri.conf.json`, закрытый хранится вне репозитория (`%USERPROFILE%\.tauri\folio-updater.key`, а в GitHub — секрет `TAURI_SIGNING_PRIVATE_KEY`). Без закрытого ключа сборка выпуска не сможет подписать обновление, и установленные копии его не примут.
